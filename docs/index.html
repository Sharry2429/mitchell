Quickstart Guide

Mitchell runs natively on Windows, macOS, Linux, and Docker. Follow these 3 simple steps to get started:

1. Clone & Install
git clone https://github.com/Sharry2429/mitchell.git
cd mitchell
powershell -ExecutionPolicy Bypass -File scripts\install.ps1 # Or bash scripts/install.sh
2. Set API Keys (or use zero-cost offline Ollama)
# .env
GROQ_API_KEY=your_groq_key
DEEPSEEK_API_KEY=your_deepseek_key
# Or start Ollama locally: ollama run llama3.2
3. Execute Your First Goal
mitchell do "Search the latest breakthroughs in autonomous multi-agent AI"

Programmatic Python SDK (`mitchell.sdk`)

Embed Mitchell directly into any Python script, FastAPI server, or automated workflow with 3 lines of code:

import mitchell # Connect to local hive or remote mesh node hive = mitchell.connect() # 1. Execute an autonomous goal result = hive.do("Analyze stock performance for NVDA and generate summary") print(result) # 2. Voice & Speech Interactivity hive.voice.speak("Task execution finished.") # 3. Live On-Screen Visual Highlighting hive.screen.highlight(x=350, y=200, width=150, height=40, label="Search Bar") # 4. Specialized Financial Intelligence Team finance_team = hive.teams.get_team("finance_team")
