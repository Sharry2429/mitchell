Getting Started in 60 Seconds

Mitchell requires Python 3.10+ and Git. It automatically sets up virtual environments, installs Playwright Chromium, and configures SQLite databases.

Step 1: Clone Repository
git clone https://github.com/Sharry2429/mitchell.git
cd mitchell
Step 2: Run Installer
# Windows: scripts\install.ps1
# Linux/Mac: bash scripts/install.sh
Step 3: Run First Goal
mitchell do "Search latest arXiv AI papers"

Programmatic Python SDK Reference

Integrate Mitchell's autonomous decision loop into your own Python applications with just 3 lines of code:

import mitchell

# 1. Connect to local hive or remote mesh node
hive = mitchell.connect()

# 2. Execute an autonomous multi-step goal
result = hive.do("Analyze the latest stock movements for NVDA and generate summary")
print(result)

# 3. Voice TTS & Screen Highlighting
hive.voice.speak("Financial report generated successfully.")
hive.screen.highlight(x=350, y=200, label="Download Chart")

# 4. Specialized Financial Hive Team
finance_team = hive.teams.get_team("finance_team")
